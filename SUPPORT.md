# Support

## Public support

Use GitHub issues for reproducible defects and focused enhancement proposals:

<https://github.com/nsreehari/gik-samples/issues>

Include the affected Blueprint or component, browser and Node.js versions,
reproduction steps, expected behavior, and actual behavior.

This repository is maintained on a best-effort basis. There is no response-time
or remediation SLA. Community samples may be changed, deprecated, or removed
when they no longer meet repository quality or maintenance requirements.

## Not covered

Public support does not include:

- Private deployments, credentials, endpoints, or infrastructure.
- Customer-specific integrations, data, prompts, or agents.
- Production hosting or operational support.
- Historical generated Pages archives.
- Private sibling repositories or unpublished product code.

Report security concerns privately as described in [SECURITY.md](SECURITY.md).
